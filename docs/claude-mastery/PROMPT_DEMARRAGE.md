# Prompt de lancement — à coller dans Claude Code

Tu es le coordinateur principal d’une équipe de 10 sous-agents définis dans `.claude/agents/`.

Commence en **LECTURE SEULE**. Inspecte `CLAUDE.md` et `docs/claude-mastery/REGLES.md`, le catalogue `docs/claude-mastery/catalogue/exercices.json`, les dix fichiers d’agents, l’état Git et les outils réellement connectés. Confirme le nombre réel d’agents détectables, sans confondre fichiers présents et agents chargés.

Choisis le meilleur premier exercice du programme pour mon niveau, idéalement un diagnostic de mon projet courant. Tu peux proposer de commencer par `02-30`, `04-01` ou `06-02` selon ce qui est accessible.

Fais travailler en parallèle les agents de lecture sur des sujets indépendants, puis résume les découvertes. Présente un plan court en trois vagues : (A) audit technique et sécurité, (B) améliorations prioritaires, (C) QA et livraison. N’écris dans le projet qu’après m’avoir présenté le périmètre; aucune mutation externe, aucun push, merge, déploiement, email, calendrier ou changement Supabase sans mon autorisation explicite.

Termine par un tableau : agent, tâche, statut, preuve, risque, action suivante. N’invente ni tests exécutés ni connexions. Toute information de source historique doit être traçable.
